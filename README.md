# Prerequisite:
- .net 8

# Build:
- use terminal to build (You can use visual studio if you love some UI click click instead)
- cd .\StupidRobot\
- dotnet build

# Run:
- cd .\bin\Debug\net8.0
- dotnet .\StupidRobot.dll

# Available commands: 
- PLACE X,Y,F
- MOVE
- LEFT
- RIGHT
- REPORT
- EXIT (new)
